# Запуск задач через opencode

Задачи лежат в `docs/opencode-tasks.md`: сверху «Общий контекст», дальше пакеты («# … пакет задач») с блоками `## Задача N.`.

## Разрешение пользователя
Пользователь разрешил запускать `opencode run --auto` для этого проекта (внешний агент, авто-одобрение действий).
Если классификатор прав всё равно блокирует вызов — не обходить, остановиться и объяснить.

## Порядок действий
1. **Выбрать задачи.** Номера, пакет или «все незакрытые» (в заголовке нет «ЗАКРЫТА»). Спросить, только если непонятно.
2. **Порядок.** Задачи, трогающие один файл (чаще всего `src/sim.js`), — строго по очереди; в пакете это указано
   в абзаце правил. Независимые можно параллельно, но по умолчанию — последовательно. Задачу «документация» — последней.
3. **Бэкап.** Проект без git: перед запуском скопировать `src docs tools README.md styles.css index.html` в
   `<scratchpad>/backup`. Если git появился — вместо этого убедиться, что дерево чистое / сделать ветку.
4. **Промпты.** На каждую задачу файл `<scratchpad>/prompts/N.md` = «Общий контекст» + правила пакета + текст задачи
   (python-скрипт: регулярка `## Задача N\..*?(?=\n## Задача |\Z)`).
5. **Скрипт-очередь** `<scratchpad>/run.sh` (zsh): для каждого N
   `opencode run --auto -m opencode-go/glm-5.3-flash --title "megafarm task N" "$(cat prompts/N.md)" > logs/taskN.log 2>&1`,
   в `logs/progress.log` писать start/exit и в конце `ALLDONE`. Рабочий каталог — корень проекта.
6. **Запуск** через Bash с `run_in_background: true`. Не опрашивать и не спать — придёт уведомление о завершении.
7. **Модель.** По умолчанию `opencode-go/glm-5.3-flash` (проверить `opencode models | grep glm`; другого glm-5.3 в провайдере go нет).
   Другую модель — только по просьбе пользователя.

## После завершения
Модель — не доказательство. Для каждой задачи: прочитать хвост `logs/taskN.log`, сравнить с бэкапом
(`diff -ru <scratchpad>/backup/src src`), прогнать `node tools/smoke_levels.mjs` и `node tools/test_*.mjs`, проверить,
что `assets/` и `tools/ida/` не тронуты. Отчёт пользователю: что сделано, что проверено, что нет, что откатить.
Откат — копированием файла из бэкапа, только по просьбе пользователя.
