# Задачи для opencode (GLM 5.3)

Каждая задача самодостаточна: скопируйте «Общий контекст» + одну задачу в запрос. Задачи не пересекаются по файлам,
их можно давать параллельно, если не указано иное.

## Общий контекст (вставлять в каждый запрос)

Проект: `/Users/Apple/PycharmProjects/megafarm` — браузерный порт игры Farm Craft (оригинал под Windows).
Чистый JS (ES-модули), без сборки и без npm. Запуск: `python3 tools/serve.py` → http://localhost:8123/
(сервер иногда падает — перезапустить). Логический холст 800x600, меню/HUD/комиксы — DOM поверх канваса.

Структура: `src/sim.js` — симуляция уровня; `src/render.js` — отрисовка; `src/menu.js` — меню, карта, трофеи;
`src/progress.js` — прогресс/рекорды/трофеи; `src/comics.js` — комиксы; `src/ui.js` — HUD; `src/main.js` — загрузка и связка;
`src/settings.js` — настройки в localStorage; `src/data.js`/`src/dsl.js` — скрипты оригинала (`assets/…txt`, DSL `@node`, `#prop`).
Знания об оригинале: `docs/original-notes.md` (читать первым).
Отладочный объект в консоли: `window.__game` (доступен ~5 с после загрузки из-за заставки).

Правила:
- Стиль и вёрстку брать из оригинала, а не придумывать: размеры/позиции окон лежат в `assets/interfaces/*.txt`.
- Не менять `assets/` и `tools/ida/`. Текстуры и скрипты оригинала — только читать.
- Не добавлять зависимости и сборщики. Один модуль — одна ответственность, комментарии короткие, по-русски или по-английски.
- После правок: открыть игру в браузере, пройти затронутый сценарий, проверить консоль на ошибки. Отчёт: что сделано,
  что проверено, что НЕ проверено.
- Если для ответа нужно знание оригинала, которого нет в `docs/original-notes.md`, — не выдумывать: записать вопрос в
  конец `docs/open-questions.md` и сделать разумное поведение по умолчанию.
