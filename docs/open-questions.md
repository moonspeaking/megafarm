- Save/load: неизвестно, что в оригинале делает ветка «НЕТ» на вопрос «Загрузить сохранённую игру?»
  (сохраняется ли <profile>.sav). Порт по умолчанию: «НЕТ» начинает уровень заново и удаляет сейв этого уровня.
- Save/load: не проверено, хранится ли в оригинале ровно один сейв на профиль (а не на уровень/слот).

- Save/load: не проверено, сохраняет ли оригинал позицию/маршрут героини в движении. Порт по умолчанию:
  при загрузке героиня стоит на сохранённой точке, текущие задача/маршрут/анимация сбрасываются
  (как и AI-цели работников: они переоцениваются после загрузки).

  вопрос question_saveandexit_game). Порт по умолчанию: пункт добавлен с запасным текстом
  (rus «Сохранить и выйти» / eng «Save and exit»), подтверждение не показывается.
- Save/load: не проверено, пишется ли в оригинале сейв автоматически при победе; порт по умолчанию
  удаляет сейв уровня при победе (после загрузки старого сейва вопрос больше не задаётся).

  направление роста текста неясно). Порт по умолчанию: 256 px шириной, текст вниз от pos (смещения
  подсказок в trophyroom.txt примерно «центр трофея + (50,55)»).
