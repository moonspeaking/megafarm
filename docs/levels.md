# Справочник уровней

Сгенерирован скриптом `tools/gen_levels_doc.mjs` из скриптов оригинала: `assets/scripts/level1..12.txt`,
`assets/scripts/objects/*.txt`, локализация `assets/scripts/rus.txt`. Не редактировать вручную —
перегенерировать: `node tools/gen_levels_doc.mjs`.

Уровень 0 (`level0.txt`, «пробный») в кампанию не входит. Условия с гигантскими порогами `time`
(например `time >= 300000000000000`) в оригинале фактически никогда не срабатывают — приведены как есть.
