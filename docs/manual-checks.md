# Ручные сценарии проверки

## Задача 11. Сенсорное управление и масштабирование

Десктопная мышь (Chrome/Firefox):
1. `python3 tools/serve.py` → http://localhost:8123/, дождаться меню.
2. ЛКМ по полю уровня 1: героиня идёт, ставит/копает по двойному тапу (два быстрых клика) — как раньше.
3. ПКМ по полю: контекстное меню браузера не появляется, действие правого клика в игре срабатывает.
4. Изменить размер окна (в т.ч. после devtools-zoom): картинка всегда 4:3, ничего не обрезано, HUD не уехал; FPS/blurry — по настройке «сглаживание».
5. Консоль пустая (без ошибок) после старта уровня, паузы и выхода.

Touch-устройство или DevTools → Device toolbar:
1. Коснуться поля: герой идёт к точке касания; двойной тап — двойное действие; long-press по канвасу НЕ открывает контекстное меню браузера и НЕ вызывает правый клик игры.
2. Достать/пролистать ленту магазина внизу (горизонтальный свайп) — прокручивается, тап по предмету покупает.
3. Тапы по вкладкам магазина, слоту лопаты, «ОК» в окнах сообщений и кнопке меню — работают без задержки и без синей подсветки тапа.
4. Тап по канвасу не вызывает зум/скролл страницы (двойной тап не приближает).
5. Повернуть устройство / скрыть-показать адресную строку: масштаб обновляется, поле 4:3 целиком видно без обрезки.
6. Свернуть-развернуть с экранной клавиатурой (если применимо на устройстве): после закрытия клавиатуры масштаб корректен (это случай visualViewport).

Не проверяется автоматикой (см. `tools/smoke_levels.mjs` — только симуляция без ввода): все пункты выше требуют браузера.

## Задача 18. Устойчивость игрового цикла

Требует браузера (`python3 tools/serve.py` → http://localhost:8123/), автоматикой не проверяется.

Ошибка в обновлении мира (основной сценарий):
1. Начать любой уровень (например, 1), дать героине дойти до огорода.
2. Открыть консоль и подставить искусственный бросок: `__game.world.update = () => { throw new Error('x') }`.
3. В пределах кадра появляется компактная панель (в стиле `.mwin`) с текстом «Ошибка: …» и кнопкой «В меню»;
   игра замирает (героиня больше не двигается, время не идёт).
4. В консоли ОДНА запись `Ошибка игрового цикла: … Error: x …` (не по одной на кадр); панель не дублируется
   и не мелькает повторно ни через 1, ни через 10 секунд.
5. Нажать «В меню»: панель исчезает, HUD скрыт, показывается главное меню.
6. Снова начать уровень: игра работает (панельное состояние сброшено). Снова подставить throw — панель появляется
   вновь (один раз на инцидент).

Ошибки вне игрового цикла:
1. В консоли браузера: `setTimeout(() => { throw new Error('y') })` → `window.onerror` показывает ту же панель «Ошибка: …».
2. В консоли: `Promise.reject(new Error('z'))` → `unhandledrejection` показывает ту же панель.
3. В обоих случаях — по одной записи в консоли, панель одна (повторный показ подавлен, пока не нажали «В меню»).
4. После «В меню» обычные уровни стартуют и играются без ошибок в консоли.

Что НЕ проверено автоматикой: 2D-отрисовка панели, клик «В меню» и всё выше — только вручную в браузере.
`node --check src/main.js` и `tools/smoke_levels.mjs` проверяют только синтаксис и симуляцию.

## Задача 34. Звуки, HUD магазина, уровень 0 и локализация

Всё ниже требует браузера (`python3 tools/serve.py` → http://localhost:8123/) — не проверено автоматикой.
Логика таймеров/счётчиков уже покрыта `tools/test_sim_rules.mjs`, здесь проверяется слышимость и вид.

### Фоновые звуки уровня (ambient)
1. Начать уровень 1 (трава): через ~1 с после старта и далее раз в 6–12 с звучит один из
   `birds1..4.ogg` (случайный выбор), каждый звук один раз, без самоповтора.
2. Начать уровень 5 (болото): раз в 20–25 с звучит `swamp1.ogg` (первый — тоже через ~1 с).
3. Начать уровень 6 (пустыня): раз в 20–25 с звучит `desert1.ogg`.
4. Сохраниться посреди уровня и загрузить сохранение: первый фоновый звук снова через ~1 с
   (таймер окружения не сохраняется — так и задумано).

### Звуки героини
1. Полить растение с лейкой в руках: в момент начала полива звучит `watercan.ogg` (один раз на действие).
2. С лейкой (можно пустой) кликнуть по колонке (waterpump): при заправке звучит `waterpump.ogg`.
3. Краном (transporter) переместить дом/ангар/дерево: в момент клика-подтверждения звучит `transporter.ogg`.
4. Кликнуть по корове/свинье/овце/курице: звучит её `name_sfx` из скрипта объекта
   (`cow/pig/sheep/chicken_sfx.ogg`); клик по улью — `bees_sfx.ogg`.

### Конец уровня
1. Быстро пройти уровень 1 в пределах его `level_time` (золотой результат, новый трофей):
   окно конца уровня + `add_trophy.ogg`, затем комната трофеев с объявлением.
2. Пройти тот же уровень второй раз медленнее (без золота, трофей уже есть):
   `next_level.ogg`, после — карта со следующим выбранным уровнем (после 12-го — финальные комиксы).

### Кнопки магазина (нижняя панель)
1. Начать любой уровень и посмотреть на нижнюю панель: кнопки предметов полупрозрачные —
   это извлечённая альфа `item_shop_menu.png` (≈ 75/255, скруглённые панели).
2. Навести курсор на кнопку: показывается нижний кадр того же спрайта (подсветка,
   `background-position 0 -58px`); при уходе курсора возвращается верхний кадр.
3. При нехватке денег кнопка дополнительно приглушена (opacity .55); клик по ней —
   уведомление «Не хватает денег!», а не покупка.

### Уровень 0: готовые грядки и разбрызгатель на дробных координатах
1. Уровень 0 в кампанию не входит, на карте его монеты нет — запускать только из консоли
   (объект доступен ~5 с после загрузки из-за заставки): `__game.startLevel(0)`.
   Может не стартовать из консоли — не проверено.
2. Сетки «none 4 3» / «none 5 1» из скрипта показаны как уже вскопанные грядки без растений
   (мокрый коричневый вид, травяные кромки по свободным сторонам).
3. Разбрызгатель уровня 0 стоит в (13.5, 7.5): синяя зона полива выровнена по сетке клеток
   (не съезжает на полклетки), эллипс соответствует `sprinkle_radius`; сам разбрызгатель вращается.
4. На уровне 4 разбрызгатель стоит в (6.5, 8.5) — зона выровнена так же.

### Английский язык
1. В настройках выбрать язык English: имена уровней на карте и в подсказке у монетки —
   ключи `level1_name`…`level12_name` из eng-пака (например, «Training»), а не «Уровень N».
2. Вызвать уведомления (покупка без денег, пустая лейка, погибшее растение, работник ждёт оплаты):
   тексты `notify_*` на английском — из eng-пака, а для портовых ключей — из `src/i18n_extra.js` (eng).

### Уровень 4: подсказки про комбайн
1. Начать уровень 4 через интерфейс: главное меню → «Старт» → карта → выбрать монету уровня 4 →
   «Старт» → пропустить комикс. Через ~3 с появляется окно
   `l4_message_harvester_help` — знакомство с комбайном (Василием).
2. Дождаться, пока комбайн остановится и над ним появится монетка: окно
   `l4_message_harvester_money_help` (счётчик `worker_coin ≥ 1`); клик по комбайну платит ему
   100 монет (`pay.ogg`), и он снова приступает к работе.
3. Оставить комбайну нечего собирать (всё спелое собрать/продать): над его головой «?» и окно
   `l4_message_harvester_question_help` (счётчик `worker_question ≥ 1`, один раз за цикл работы).
